# Korea Four-Insurance (Employee Share) Reference (2026-02)

This doc is used for "4대보험(예상)" UI calculations in the app. It is an estimate and does not cover exceptions.

## Rates (employee share)
- 국민연금: 4.75%
- 건강보험: 3.595%
- 장기요양보험: 0.4724% (소득 대비 0.9448%의 50%로 계산)
- 고용보험(실업급여): 0.9%

## Notes
- 산재보험은 근로자 공제(세후 계산)에서 제외(사업주 부담).
- 실제 공제는 각종 조건(소득구간, 사업장/근로자 유형, 과세/비과세 등)에 따라 달라질 수 있음.

## Sources (official)
- 국민연금 보험료율: NPS
- 건강보험료율/장기요양보험료율: 보건복지부
- 고용보험(실업급여) 요율: 고용보험
