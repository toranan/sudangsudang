# ADR 0001: 근태와 급여의 시간 경계를 KST로 고정

- 상태: Accepted
- 결정일: 2026-07-11

## Context

근무 기록은 절대 시각으로 저장하지만 근무일, 주차, 월별 정산, 야간수당은 지역 시간 경계에 의존합니다. 기기 설정을 그대로 사용하면 같은 기록도 사용자 시간대에 따라 다른 날짜와 급여로 분류될 수 있습니다.

## Decision

업무 규칙의 시간대는 `Asia/Seoul`로 고정합니다. `AppTime`이 KST 그레고리력, ISO8601 파서, 화면용 포매터를 제공하고 근태/급여 계산은 이를 사용합니다.

## Consequences

- 한국 매장 기준으로 월 경계와 22:00~06:00 야간 구간이 일관됩니다.
- 화면별 `Calendar.current`와 임의 포매터 중복을 줄일 수 있습니다.
- 해외 매장 지원 시 매장별 시간대를 저장하는 후속 설계가 필요합니다.
- KST 고정만으로 주휴수당의 주 경계 입력 문제까지 해결되지는 않습니다.

## Verification

현재는 빌드와 수동 시나리오로 확인했습니다. 자정, 월말, 연말, 22:00/06:00 경계의 자동 테스트는 추가해야 합니다.
